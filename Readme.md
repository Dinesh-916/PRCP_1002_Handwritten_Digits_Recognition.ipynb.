# Handwritten Digits Recognition Using Machine Learning and Deep Learning

## 1. Project Overview

This project implements a handwritten digit recognition system using the MNIST dataset. The primary objective is to classify handwritten numerical digits from 0 to 9 using machine learning and deep learning techniques.

The project includes exploratory data analysis, image preprocessing, model development, performance evaluation, and prediction analysis.

## 2. Dataset Description

The project uses the MNIST handwritten digit dataset.

- Total images: 70,000
- Training images: 60,000
- Testing images: 10,000
- Image dimensions: 28 × 28 pixels
- Image format: Grayscale
- Number of classes: 10 (digits 0–9)
